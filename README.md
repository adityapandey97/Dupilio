# Profiler

AI-Powered SDE Placement Platform & Developer Profile Analyzer.

## Overview
Profiler (HirePrep) is a full-stack platform designed to help developers prepare for software engineering placements with AI-driven resume analysis, curated coding challenges, and mock interview tools.

## Architecture
- **Frontend**: React + Vite + Tailwind CSS / Vanilla CSS
- **Backend**: Node.js + Express
- **AI Engine**: Python (FastAPI / Analyzers / Scrapers)

## Getting Started

### Prerequisites
- Node.js (v18+)
- Python (3.10+)

### Installation
```bash
npm run install-all
```

### Development
```bash
npm run dev
```

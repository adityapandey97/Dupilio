# DUPILIO — AI Intelligence Architecture & Prompt Engineering

> **Brand Statement**: *One profile. Every opportunity. A smarter path to your next role.*

---

## 1. Overview & Service Boundaries

DUPILIO maintains a strict operational separation between **Deterministic Calculation** (executed in code) and **Interpretive Intelligence** (delegated to LLMs and Python AI analyzers).

```
User Action / Profile Telemetry
             ↓
Deterministic Code Engine (Node.js & Python)
  - Scores, metrics, counts, percentiles, benchmark ratios
             ↓
Structured Evidence Schema (JSON)
             ↓
FastAPI AI Microservice (Port 8000)
             ↓
Explainable Interpretations, Weakness Diagnoses & Actionable Plans
```

### Critical Rule
Never ask an LLM to calculate something that can be reliably and deterministically computed in code (e.g. contest ratings, problem counts, percentages, streak lengths, match scores). The LLM's role is strictly **interpretation, contextualization, explainability, and natural language synthesis**.

## 2. AI Endpoints & Contracts

The Python AI Microservice (`ai_engine/main.py`) provides the following endpoints:

| Endpoint | Method | Input Contract | Output Contract |
| :--- | :--- | :--- | :--- |
| `/api/parse-command` | `POST` | `{ "prompt": string, "userId": string }` | Structured action intent (`create_reminder`, `create_todo`, `query_contests`, `plan_preparation`) with parameters and confidence score |
| `/api/analyze-profile` | `POST` | `{ "leetcode": string, "github": string }` | Multi-platform gap telemetry, topic mastery array, fall points, and placement readiness index |
| `/api/generate-plan` | `POST` | `{ "timeFrameDays": int, "dailyHours": float, "weakAreas": list }` | Structured day-by-day milestone roadmap addressing identified drop-off topics |
| `/api/recommend-problems` | `POST` | `{ "weakAreas": list, "solvedCount": int, "targetPlatform": string }` | Targeted practice questions with explicit rationale and direct official URLs |
| `/api/chat` | `POST` | `{ "prompt": string, "userContext": dict }` | Context-aware copilot guidance referencing user's verified stats |

## 4. Prompt Engineering Architecture (Section 93)

All prompts dispatched to LLM providers are fed structured JSON evidence rather than uncurated database dumps:

1. **Profile Diagnostic Prompt**: Inputs include normalized topic mastery, difficulty ratios, contest rating, and GitHub repo distribution.
2. **Resume ATS Gap Prompt**: Inputs include parsed resume skills, target role (e.g. SDE-1), and detected keyword discrepancies.
3. **Natural Language Action Parser**: Inputs include user text commands, mapping utterances into executable JSON actions without executing arbitrary database code.

---

## 5. Fault Tolerance & Fallback Strategy

1. **Network Timeout Guard**: Node.js calls to the Python microservice enforce a 3.5-second timeout via `AbortController`.
2. **Deterministic In-Process Parser**: If the Python service is unreachable or rate-limited, Node.js transparently falls back to its deterministic regex/NLP parser (`ai.controller.js`).
3. **No Crash Guarantee**: Malformed LLM responses are intercepted, validated against Pydantic schemas, and replaced with deterministic rule-based advice.
